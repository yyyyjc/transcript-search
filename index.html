隱私說明

本工具處理資料的流向：

  • Google 帳號：僅用於讀取你 Drive 中指定資料夾的逐字稿檔案。本工具不寫入、不刪除、不修改任何 Drive 內容。
  • 逐字稿內容：搜尋時，命中段落會傳送到本團隊自架的 Cloudflare Worker、再轉送到 Anthropic Claude API 做語意分析。
  • Anthropic Claude API：依 Anthropic 政策，企業 API 用戶的請求預設不用於模型訓練。
  • 不保存：本工具不在伺服器端保存任何逐字稿、查詢、結果。瀏覽器本機 localStorage 僅保存「今日累計成本」此小資料。
  • 權限控管：誰能用、誰看得到，完全由 Drive 資料夾分享名單決定。媒體組以外的人即使知道網址也讀不到內容。

如有疑問請洽工具維運者。
